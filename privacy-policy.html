Политика конфиденциальности

Эта политика описывает обработку информации в мобильном приложении Daily Guess («Один в день»).

1. Игровые данные

Приложение предназначено для ежедневного решения загадок. Игровой прогресс, ответы и настройки могут сохраняться локально на устройстве, чтобы приложение работало корректно. Эти данные могут быть удалены при очистке данных приложения или его удалении.

2. Уведомления

Приложение может запрашивать разрешение на уведомления для напоминаний о ежедневной загадке. Разрешение можно отозвать в настройках устройства.

3. Личные данные и сторонние сервисы

Для использования основных игровых функций не требуется создавать учётную запись или предоставлять имя, адрес либо контактные данные. Если пользователь добровольно обращается по электронной почте, разработчик получает сведения, содержащиеся в сообщении, и использует их для ответа.

Фактическая обработка технических данных сторонними библиотеками (например, средствами диагностики, аналитики, рекламы или доставки уведомлений) зависит от состава опубликованной версии приложения. До публикации необходимо проверить используемые библиотеки и при необходимости дополнить эту политику соответствующими сведениями.

4. Дети

Приложение не требует предоставления персональных данных для решения загадок. Если обработка данных или целевая аудитория приложения изменится, эта политика будет обновлена с учётом применимых требований.

5. Безопасность и хранение

Локальные игровые данные хранятся на устройстве пользователя. Пользователь может удалить их через настройки устройства. Переписка по электронной почте хранится в почтовом сервисе в объёме, необходимом для ответа и обработки обращения.

6. Изменения политики

При изменении функций приложения или практик обработки данных эта страница будет обновлена. Актуальная версия доступна по адресу https://nicatsoltanov-ai.github.io/daily-guess/privacy-policy.html.

7. Контакты

Privacy Policy

Effective date: November 23, 2026
Developer: Nicat Soltanov
Contact: NicatSoltanov@gmail.com

This policy explains how information is handled in the Daily Guess (“Один в день”) mobile application.

1. Game data

The app provides a daily puzzle experience. Game progress, answers and preferences may be stored locally on the device to support app functionality. Such data may be removed by clearing app data or uninstalling the app.

2. Notifications

The app may request notification permission to remind users about the daily puzzle. This permission can be revoked in device settings.

3. Personal information and third-party services

Users do not need to create an account or provide a name, address or contact details to use the core puzzle features. If a user voluntarily contacts the developer by email, the developer receives the information included in that message and uses it to respond.

The actual handling of technical information by third-party libraries (such as diagnostics, analytics, advertising or notification delivery services) depends on the published app build. Before publication, the libraries used must be verified and this policy updated as necessary.

4. Children

The app does not require users to provide personal information to solve puzzles. If data handling or the intended audience changes, this policy will be updated to address applicable requirements.

5. Security and retention

Local game data remains on the user's device and can be removed through device settings. Email correspondence is retained by the email provider as necessary to respond to and handle requests.

6. Changes to this policy

This page will be updated when app features or data practices change. The current version is available at https://nicatsoltanov-ai.github.io/daily-guess/privacy-policy.html.

For privacy questions, email NicatSoltanov@gmail.com.
